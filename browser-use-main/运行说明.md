# 运行说明（迁移到新机器 / 给 Agent 看的操作手册）

> 本文件是**自包含**的部署与运行手册，目标读者是「另一台机器上的 AI agent 或人」。
> 按本文从上到下执行即可把项目跑起来。所有路径均相对于本目录 `browser-use-main/`。

---

## 0. 这是什么

一个基于 **vendored（项目内置、已魔改）的 browser-use 库** 的 LLM 浏览器爬虫：
让 Agent 自动在目标网站（主要是 `idp.bl.uk` 等带搜索栏的图库站）搜索关键词、翻页、
批量下载图片 item、提取信息，并把进度持久化到本地 `ImagesCache/` 缓存目录。

主要障碍是目标站的 **Cloudflare Turnstile 人机验证**。本项目已内置应对手段（见第 6 节）。

### 给 Agent 的关键事实（务必先读）

- **操作系统假定 Windows + PowerShell**。Linux/macOS 把反斜杠路径换成正斜杠、`.venv\Scripts\` 换成 `.venv/bin/` 即可。
- **编码坑（必做）**：脚本含中文/emoji，直接 `python xxx.py` 在 Windows 控制台会报 `UnicodeEncodeError`。
  运行任何脚本前先设：`$env:PYTHONIOENCODING='utf-8'`。
- **browser-use 是本地内置的**（`browser_use/` 目录），**不要** `pip install browser-use` 覆盖它。用 `pip install -e .` 安装本地版。
- **不要硬编码绝对路径**。代码里用相对路径（相对脚本位置）。
- **LLM 默认走 SEU 接口**（`https://openapi.seu.edu.cn/v1`，需校园网/VPN）。换 LLM 见第 4 节。
- 反爬的真实 Chrome / 代理配置，三个入口（main / supervisor / GUI）**共用同一组 `IDP_*` 环境变量**，已打通。

## 2. 一次性安装

```powershell
# 进入项目目录（本文件所在目录）
cd <你克隆下来的路径>\browser-use-main

# 建虚拟环境
python -m venv .venv

# 激活
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS/Linux

# 安装本地内置的 browser-use 及全部依赖（注意是 -e . 安装当前目录，别装 PyPI 版）
pip install -e .
# 国内镜像加速可选：
# pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 本项目通过 `cdp-use` 直连**系统已安装的 Chrome/Chromium**（CDP 协议），
> **不需要** `playwright install`。只要机器上装了 Chrome/Chromium，程序会自动检测使用。

## 4. 配置 LLM（必做）

`main.py` 从环境变量读取，**无需改代码**：

| 变量 | 说明 | 默认 |
|------|------|------|
| `OPENAI_API_KEY` | **必填**，没有会直接报错退出 | 无 |
| `OPENAI_BASE_URL` | OpenAI 兼容接口地址 | `https://openapi.seu.edu.cn/v1` |

模型名当前写死在 `main.py`（约 L1082）`model='qwen3.5-397b-a17b'`。换模型/换服务商时修改这一行，并设置对应 `OPENAI_API_KEY` / `OPENAI_BASE_URL`。

PowerShell 临时设置示例：

```powershell
$env:OPENAI_API_KEY = '你的key'
$env:OPENAI_BASE_URL = 'https://api.deepseek.com/v1'   # 例：换成 DeepSeek
```

> 任何 OpenAI 兼容接口都可用（DeepSeek、通义千问 compatible-mode、OpenAI 官方等）。
> 启动时会做一次 `preflight_llm_check` 连通性探测，失败会提示检查网络/key。

## 5. 三种运行入口（选一个）

> 运行前都先：`$env:PYTHONIOENCODING='utf-8'`，并确保已激活 `.venv`。

### 5.1 单次运行 —— `main.py`
跑一轮 Agent（读 `task.md` → 清理 image → 搜索下载 → 重命名）。适合调试。

```powershell
$env:PYTHONIOENCODING='utf-8'; python main.py
```
运行中输入 `quit`+回车 安全停止；`Ctrl+C` 强制中断。

### 5.2 监督循环（推荐）—— `auto_run_until_target.py`
把 `main.py` 当子进程**反复重启**，直到 `ImagesCache/` 达到 `task.md` 里的目标数；
内置断点续跑、自适应冷却（被限流时指数退避）、卡死超时清理。

```powershell
# 续跑：从上次断点继续（同一个关键词接着下）
$env:PYTHONIOENCODING='utf-8'; python auto_run_until_target.py --resume

# 全新开跑某关键词（归档旧缓存，目标 5000 张）
$env:PYTHONIOENCODING='utf-8'; python auto_run_until_target.py --new-run --keyword "china buddhist" --target 5000
```

`--resume` vs `--new-run` 必须二选一：
- `--resume`：第一轮从上次断点页码继续，**不清空**已下载缓存。
- `--new-run`：归档旧 `ImagesCache/` 到存档目录，从头开始。
- 换了 `--keyword` 且与当前不同，会自动归档旧缓存并改写 `task.md`。

常用参数（均有默认，可不填）：

| 参数 | 含义 | 默认 |
|------|------|------|
| `--keyword` | 搜索词（非交互写入 task.md） | 沿用当前 |
| `--target` | 目标下载总数 | 沿用 task.md |
| `--max-rounds` | 最大重启轮数 | 100 |
| `--max-no-progress-rounds` | 连续无新增多少轮后停止 | 3 |
| `--page-delay-seconds` | 每页下载前节流秒数（降 Cloudflare 限流概率） | 12 |
| `--cooldown-seconds` | 无进展时基础冷却秒数（指数递增） | 60 |
| `--round-timeout` | 单轮最长秒数，超时判卡死清理；0=不限 | 0 |

### 5.3 图形界面 —— `run_gui.py`
tkinter 前端，托管上面的 supervisor，实时显示日志/进度，一键停止。
表单里可填：关键词、目标数、LLM key/base_url、并发数、真实 Chrome/代理字段、resume/new-run 模式。

```powershell
$env:PYTHONIOENCODING='utf-8'; python run_gui.py
```
窗口的「Python 解释器」默认就是当前 `sys.executable`，子进程用它来跑。

## 6. 应对 Cloudflare 人机验证（重要）

**原理**：目标站的 Cloudflare Turnstile 主要按「后台浏览器指纹 + IP 信誉」判定，
**不是**靠「点没点中复选框」。所以脚本里模拟点击/视觉点击**解决不了**——闸门不在点击。
真正有效的是：**用一个带真实 cookie / `cf_clearance` 的真实 Chrome profile 出场**，必要时再叠加干净 IP 的代理。

### 启用真实 Chrome profile
三个入口共用同一组环境变量（也可用 CLI 参数 / GUI 字段，最终都写入这些变量）：

| 环境变量 | 含义 |
|----------|------|
| `IDP_CHROME_EXECUTABLE` | 真实 Chrome 可执行文件路径 |
| `IDP_CHROME_USER_DATA_DIR` | Chrome 用户数据目录 |
| `IDP_CHROME_PROFILE_DIRECTORY` | profile 子目录名（默认 `Default`） |

> **必须同时设 `IDP_CHROME_EXECUTABLE` + `IDP_CHROME_USER_DATA_DIR` 且路径存在**，才会启用真实 Chrome；
> 否则自动回退到项目内置 Chromium（不破坏原行为）。

**使用前提（缺一可能失败）：**
1. 先用该 profile **手动**浏览器打开一次目标站、通过验证，让 `cf_clearance` cookie 落到该 profile。
2. 跑之前**完全关闭**那个 Chrome（profile 被占用会启动失败）。
3. 建议**单独建一个 profile 目录**，别用日常 `Default`。

PowerShell 示例：

```powershell
$env:PYTHONIOENCODING='utf-8'
$env:IDP_CHROME_EXECUTABLE   = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
$env:IDP_CHROME_USER_DATA_DIR = 'C:\Users\<你>\bu-chrome-profile'   # 一个专用目录
$env:IDP_CHROME_PROFILE_DIRECTORY = 'Default'
python auto_run_until_target.py --resume
```

或用 CLI 参数（等价）：
```powershell
python auto_run_until_target.py --resume `
  --chrome-executable "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  --chrome-user-data-dir "C:\Users\<你>\bu-chrome-profile"
```

### 可选：叠加代理（攻击 IP 信誉层）
若真实 Chrome 仍被挡，多半是 IP 信誉问题，加住宅代理：

| 环境变量 | 含义 |
|----------|------|
| `IDP_PROXY_SERVER` | 代理地址，如 `http://user:pass@host:port` |
| `IDP_PROXY_BYPASS` | 绕过列表（仅 main.py 支持，GUI/CLI 未暴露） |
| `IDP_PROXY_USERNAME` / `IDP_PROXY_PASSWORD` | 代理账密（也可直接写进 URL） |

```powershell
$env:IDP_PROXY_SERVER = 'http://user:pass@your-proxy:8080'
```
> CLI 对应 `--proxy-server`；GUI 有「代理服务器」输入框。账密直接写进 URL 即可，无需单独设 username/password。

### 还不行的下一档
住宅代理仍被挡 → 考虑 Browser-Use Cloud（`use_cloud=True`，需付费 API key，见 `CLOUD.md`）。

## 7. `task.md` —— Agent 的任务指令

Agent 启动时读取 `task.md` 作为指令。supervisor 用 `--keyword` / `--target` 会自动改写其中的搜索词与目标数。
手动改时关注：搜索关键词、目标网站 URL、下载数量。**改任务行为优先改 `task.md`，而不是改 `main.py` 逻辑。**

## 8. 故障排查

| 现象 | 处理 |
|------|------|
| `UnicodeEncodeError` / 中文乱码 | 没设 `$env:PYTHONIOENCODING='utf-8'`，补上 |
| 启动报 `未设置 OPENAI_API_KEY` | 设 `OPENAI_API_KEY`（第 4 节） |
| LLM 连接超时 / 403 | 检查校园网/VPN、`OPENAI_BASE_URL`、key 是否正确 |
| 真实 Chrome 启动失败 | 那个 Chrome 没关干净（profile 被占用），全部关掉再跑 |
| 设了 Chrome 路径但仍走内置 Chromium | `IDP_CHROME_EXECUTABLE` 或 `IDP_CHROME_USER_DATA_DIR` 没同时设、或路径不存在（会打印警告回退） |
| 一直被 Cloudflare 挡、0 新增 | 先种 `cf_clearance`（第 6 节前提），再加住宅代理 |
| 下载的图片在哪 | `image/`（单轮）与持久缓存 `ImagesCache/`；旧文件归档到 `history/` |
| 想验证代码不调 LLM | `python test_main.py`（纯功能测试） |

## 9. 环境变量速查

**LLM**：`OPENAI_API_KEY`(必填)、`OPENAI_BASE_URL`
**反爬-Chrome**：`IDP_CHROME_EXECUTABLE`、`IDP_CHROME_USER_DATA_DIR`、`IDP_CHROME_PROFILE_DIRECTORY`
**反爬-代理**：`IDP_PROXY_SERVER`、`IDP_PROXY_BYPASS`、`IDP_PROXY_USERNAME`、`IDP_PROXY_PASSWORD`
**节流/调度**：`BROWSER_USE_PAGE_DELAY_SECONDS`、`BROWSER_USE_COOLDOWN_SECONDS`、`BROWSER_USE_ROUND_TIMEOUT`、`BROWSER_USE_STEP_TIMEOUT`、`BROWSER_USE_LLM_TIMEOUT`
**其他**：`PYTHONIOENCODING=utf-8`(必设)、`BROWSER_USE_IMAGE_DOWNLOAD_CONCURRENCY`、`BROWSER_USE_DISABLE_INPUT_MONITOR`
